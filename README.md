# Mattermost Database Query Bot

A Python Flask application that acts as a custom integration for Mattermost. This bot allows users to query specific customer details and PPPoE/IP assignments directly from a PostgreSQL database using Mattermost Slash Commands.

## Features

- **Slash Commands**: Integration with Mattermost via `/id` and `/pppoe` commands.
- **Slash Commands**: Integration with Mattermost via `/id`, `/pppoe`, and `/search` commands.
- **Database Integration**: Fetches real-time data from a PostgreSQL database.
- **JSON Formatting**: Returns results in a clean, formatted JSON block.
- **Logging**: Supports both human-readable (text) and machine-readable (JSON) logging formats.
- **Dockerized**: Ready for deployment using Docker and Docker Compose.
- **Type Safety**: Uses modern Python 3.12 features and type hints.

## Endpoints

- **`/query/id`**: Queries customer details (e.g., name, status, IBAN, email, phone).
- **`/query/search`**: Searches for customers by a given phrase.
- **`/query/pppoe`**: Queries hardware IP configurations.

## Configuration

The bot requires a `.env` file to securely load database credentials and Mattermost validation tokens. Copy the example file and fill in the values:

```bash
cp .env.example .env
```

### Environment Variables

| Variable       | Description                    | Default      |
| -------------- | ------------------------------ | ------------ |
| `DB_HOST`      | Database host                  | `localhost`  |
| `DB_NAME`      | Database name                  | `postgres`   |
| `DB_USER`      | Database user                  | `postgres`   |
| `DB_PASS`      | Database password              | **Required** |
| `DB_SCHEMA`    | Database schema                | `public`     |
| `ID_TOKEN`     | Mattermost token for `/id`     | **Required** |
| `PPPOE_TOKEN`  | Mattermost token for `/pppoe`  | **Required** |
| `SEARCH_TOKEN` | Mattermost token for `/search` | **Required** |
| `FLASK_PORT`   | Port for the bot               | `5000`       |
| `FLASK_DEBUG`  | Enable debug mode              | `false`      |
| `LOG_FORMAT`   | Log format (`text` or `json`)  | `text`       |

## Installation & Running

### Using Poetry (Local Development)

1. **Install dependencies**:

   ```bash
   poetry install
   ```

2. **Run the bot**:
   ```bash
   poetry run python mattermost.py
   ```

### Using Docker Compose (Recommended for Production)

1. **Build and start the containers**:
   ```bash
   docker-compose up -d --build
   ```

The application will be available at `http://localhost:5000`.

## Mattermost Setup

Go to **Integrations > Slash Commands** in your Mattermost interface and create three commands:

### 1. The `/id` Command

- **Command:** `id`
- **Request URL:** `http://<your-server-ip>:5000/query/id`
- **Request Method:** POST
- _Copy the Token generated by Mattermost to `ID_TOKEN` in your `.env`._

### 2. The `/pppoe` Command

- **Command:** `pppoe`
- **Request URL:** `http://<your-server-ip>:5000/query/pppoe`
- **Request Method:** POST
- _Copy the Token generated by Mattermost to `PPPOE_TOKEN` in your `.env`._

### 3. The `/search` Command

- **Command:** `search`
- **Request URL:** `http://<your-server-ip>:5000/query/search`
- **Request Method:** POST
- _Copy the Token generated by Mattermost to `SEARCH_TOKEN` in your `.env`._
